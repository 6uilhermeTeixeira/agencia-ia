# Agência IA

Página standalone para uma agência de IA com catálogo de 15 produtos, páginas internas de serviço e CTA configurável para WhatsApp.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## WhatsApp

Configure o número de destino com:

```bash
VITE_WHATSAPP_NUMBER=5511999999999
```
